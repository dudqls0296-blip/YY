# ASHEN THRONE — Graduation Showcase (V3)

`발표_시작.bat` 또는 `index.html`로 실행 (Chrome / Edge 권장, 인터넷 없이도 동작).

## 조작
→ / ← 장면 이동 (클리커 가능) · ↑ ↓ 항목 이동 · Enter 선택 · M 장면 선택 · Esc 타이틀 · S 사운드 · F 전체 화면

## 구성 메모
- ARSENAL의 캐릭터 · 그레이트 소드 이미지는 Unity 프로젝트의 실제 모델 파일(FBX)을 렌더링한 것입니다 (media/knight_render.png, greatsword_render.png).
- 보스 패턴 장면은 보스전 플레이 영상(media/boss_full.mp4, 약 3분 17초)이 계속 재생되고, → / ↓ 를 누를 때마다 왼쪽 설명이 다음 패턴으로 바뀝니다. 12번째 패턴 다음에 → 를 누르면 다음 장면으로 넘어갑니다.
- 상단 바와 타이틀 메뉴에 FULLSCREEN 버튼이 있습니다 (F 키도 동일).
